# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Delegated by the user: a mobile installable web app backed by a small Python service on the existing Tencent server.

## Users

People who want to record meals, understand estimated calories, and share food stickers with a companion.

## Product Purpose

Recreate the core workflows of the referenced 轻果健康 app, prioritizing the mobile interface, photo-based food and calorie recognition, automatic food stickers, and shared viewing.

## Capabilities and Constraints

Run alongside existing services without replacing the existing blog. Support user-configured DeepSeek and OpenAI API credentials. Food estimates must be editable. Sharing must require an explicit action.

## Brand Commitments

The public App Store screenshots of 轻果健康 are visual references; this is an independent open-source implementation.
